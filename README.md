# Лендінг психолога — Марта Коваль

Односторінковий сайт (landing page) для психолога-початківця з контактною
формою, яка надсилає заявки прямо в Telegram через Cloudflare Worker.

## 📁 Структура файлів

```
├── index.html   — головна розмітка сторінки (Tailwind CSS через CDN)
├── style.css    — кастомні стилі (скролбар, анімації, органічна рамка фото)
├── main.js      — логіка фронтенду (меню, скрол-ефекти, відправка форми)
├── worker.js    — Cloudflare Worker: приймає форму і пише в Telegram
└── README.md    — цей файл
```

`index.html`, `style.css` і `main.js` — це фронтенд, який хоститься на
**Cloudflare Pages**. `worker.js` — це окремий бекенд-скрипт, який хоститься
на **Cloudflare Workers**. Це два різні продукти, і деплояться вони окремо
(інструкції нижче).

---

## 1. Як запустити сайт локально

Оскільки сайт складається лише зі статичних файлів, найпростіший спосіб —
відкрити `index.html` прямо в браузері подвійним кліком.

Якщо потрібен локальний сервер (наприклад, щоб коректно перевірити
переходи по посиланнях), можна скористатись будь-яким із варіантів:

```bash
# Варіант 1: якщо встановлено Node.js
npx serve .

# Варіант 2: якщо встановлено Python 3
python3 -m http.server 8000
```

Після цього відкрийте адресу, яку покаже термінал (зазвичай
`http://localhost:3000` або `http://localhost:8000`).

На цьому етапі форма ще не працюватиме — спочатку потрібно налаштувати
Telegram-бота та задеплоїти Worker (кроки 2–3).

## 2. Створення Telegram-бота і отримання Chat ID

### 2.1. Створити бота

1. Відкрийте Telegram і знайдіть офіційного бота **@BotFather**.
2. Надішліть команду `/newbot`.
3. Вкажіть ім'я бота (будь-яке, для показу) та юзернейм (має закінчуватись на `bot`, наприклад `marta_kovalpsy_bot`).
4. BotFather надішле у відповідь **токен** виду `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   Це і є ваш `TELEGRAM_BOT_TOKEN`.

### 2.2. Дізнатися свій Chat ID

Chat ID — це ідентифікатор чату, куди бот надсилатиме заявки з сайту
(зазвичай — це ваш особистий чат з ботом).

1. Знайдіть у Telegram створеного бота за юзернеймом і натисніть **Start**.
2. Надішліть боту будь-яке повідомлення (наприклад, "привіт").
3. У браузері відкрийте адресу (підставивши свій токен):
   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```
4. У відповіді (це JSON) знайдіть поле `"chat":{"id": 123456789, ...}` —
   число і буде вашим `TELEGRAM_CHAT_ID`.

   Якщо відповідь порожня (`"result":[]`), переконайтесь, що ви щойно
   написали боту повідомлення (крок 2), і оновіть сторінку ще раз.

> 💡 Альтернатива: можна написати повідомлення боту **@userinfobot** —
> він одразу покаже ваш Chat ID без потреби відкривати `getUpdates`.

## 3. Деплой Cloudflare Worker (бекенд для форми)

### 3.1. Вставте свої дані у `worker.js`

Відкрийте `worker.js` і замініть плейсхолдери на значення з кроку 2:

```js
const TELEGRAM_BOT_TOKEN = "YOUR_TELEGRAM_BOT_TOKEN_HERE"; // ← ваш токен
const TELEGRAM_CHAT_ID = "YOUR_TELEGRAM_CHAT_ID_HERE";     // ← ваш chat id
```

> 🔒 **Порада з безпеки:** хардкодити токен прямо в коді — ок для
> невеликого особистого проєкту. Якщо плануєте викладати код у публічний
> репозиторій на GitHub, краще зберігати токен як **секрет** Worker'а
> (Settings → Variables and Secrets → Add → тип "Secret") і звертатись
> до нього як до `env.TELEGRAM_BOT_TOKEN` замість того, щоб писати
> значення прямо в файлі.

### 3.2. Задеплойте Worker через дашборд Cloudflare

Не обов'язково встановлювати жодних програм — усе робиться в браузері:

1. Зареєструйтесь / увійдіть на [dash.cloudflare.com](https://dash.cloudflare.com).
2. У лівому меню відкрийте **Workers & Pages**.
3. Натисніть **Create application** → **Create Worker**.
4. Задайте назву (наприклад, `psychologist-contact-form`) і натисніть **Deploy** — Cloudflare одразу створить робочий "Hello World" Worker.
5. Натисніть **Edit code**, видаліть весь стандартний код і вставте вміст вашого `worker.js`.
6. Натисніть **Deploy** (або стрілочку біля кнопки → **Save and deploy**), щоб опублікувати зміни.
7. Скопіюйте URL вашого Worker'а — він матиме вигляд:
   ```
   https://psychologist-contact-form.<ваш-субдомен>.workers.dev
   ```

### 3.3. Перевірте, що Worker працює

Можна надіслати тестовий запит з терміналу:

```bash
curl -X POST https://psychologist-contact-form.<ваш-субдомен>.workers.dev \
  -H "Content-Type: application/json" \
  -d '{"name":"Тест","contact":"@test","message":"Перевірка"}'
```

Якщо все налаштовано правильно, повідомлення прийде у ваш Telegram, а
у відповіді на запит ви побачите `{"success":true}`.

## 4. Підключення Worker'а до сайту

Відкрийте `main.js` і вставте URL з кроку 3.2 у змінну `WORKER_URL`:

```js
const WORKER_URL = "https://psychologist-contact-form.<ваш-субдомен>.workers.dev";
```

---

## 5. Деплой сайту на Cloudflare Pages (фронтенд)

1. У дашборді Cloudflare відкрийте **Workers & Pages**.
2. Натисніть **Create application** → оберіть вкладку **Pages** → **Upload assets** (пряме завантаження, без Git).
3. Вкажіть назву проєкту (наприклад, `marta-psycholog`).
4. Перетягніть у вікно завантаження папку з файлами `index.html`, `style.css` та `main.js` (усі три — в один рівень, без вкладених папок).
5. Натисніть **Deploy site**.
6. Готово — сайт буде доступний за адресою:
   ```
   https://marta-psycholog.pages.dev
   ```

Пізніше, у налаштуваннях проєкту (**Custom domains**), можна підключити
власний домен замість `pages.dev`.

> ⚡ **Швидка перевірка без реєстрації:** якщо хочете миттєво подивитись,
> як виглядає сайт, ще до повного деплою — можна перетягнути папку на
> [cloudflare.com/drop](https://cloudflare.com/drop). Ви одразу отримаєте
> тимчасове посилання (діє 1 годину, без потреби створювати акаунт).
> Для постійного сайту все одно використовуйте кроки 1–6 вище.

## 6. Кастомізація під себе

| Що замінити | Де шукати |
|---|---|
| Ім'я, підпис "психологиня" | `index.html` — секція `<header>` та `<footer>` |
| Фото | `index.html` — блок з коментарем `ЗАМІНІТЬ ЦЕЙ БЛОК` у секції Hero |
| Біографія і підхід | `index.html` — секція `id="about"` |
| Проблеми, з якими працюєте | `index.html` — секція `id="services"` (картки) |
| Ціни та тривалість сесії | `index.html` — секція `id="pricing"` |
| Посилання на Telegram/Instagram/email | `index.html` — секції Контакти та Footer (`href="https://t.me/..."` тощо) |
| Кольори палітри | `index.html` — блок `tailwind.config` у `<head>` |
| Текст копірайту в футері | `index.html` — самий низ, `[Your Name/Link]` |

Поточна кольорова палітра (уже налаштована в `tailwind.config`):

| Назва в коді | HEX | Використання |
|---|---|---|
| `cream` | `#FDFCF0` | основний фон |
| `mist` | `#E3E8E3` | фон для секцій-контрасту |
| `graphite` | `#333A36` | основний текст, футер |
| `moss` | `#A3B8A8` | іконки, акценти, рамки |
| `terracotta` | `#C57B57` | кнопки, CTA, активні стани |
